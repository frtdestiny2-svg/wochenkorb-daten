# Wochenkorb-Daten

Öffentliche Daten für die App Wochenkorb. Die App lädt sie von hier.

- `angebote.json`: Supermarkt-Angebote mit Produkt, Preis, Packungsgröße, Laden und Gültigkeit. Wird jeden Montag und Donnerstag automatisch aktualisiert.
- `rezepte.json`: die wöchentlich neuen Rezepte.

Die Angebote stammen von Händlerseiten und aus Prospekten und sind teils automatisch ausgelesen. Preise können falsch sein oder je nach Filiale abweichen. Keine Gewähr.
